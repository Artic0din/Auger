# Security Policy

## Supported versions

Security fixes apply to the latest published release of Auger on Samsung TVs running Tizen 8.0 or later.

## Reporting a vulnerability

Report vulnerabilities in Auger privately through GitHub's [Private Vulnerability Reporting](https://github.com/Artic0din/Auger-Tizen/security/advisories/new) instead of opening a public issue.

- Include reproduction steps, affected Auger version, TV model, and Tizen OS version.
- Never include access tokens, passwords, signing certificates, or TV DUIDs in reports.
- Vulnerabilities in Silo Server belong in the upstream [Silo-Server/silo-server](https://github.com/Silo-Server/silo-server) repository.
