# Skyline browse shell

Applies the [Skyline design guide](https://github.com/Silo-Server/silo-apple/blob/main/docs/skyline-design-guide.md) to the native browse shell (`src/ui/skyline.ts`, `src/ui/navigation.ts`, `src/ui/browse.ts`).

## Top bar, roots, and menus

- **Fixed root bar:** follows Apple `TVRootDestination.visibleRoots` (`Home · Movies · Series · Music · Audiobooks · For You · Calendar`), with Search (58 px) on the left and the Profile avatar on the right (balanced spacer keeps roots centered at x=960). Saved server menu order and custom library shortcuts do not alter the bar (`src/ui/navigation.ts`).
- **Library visibility:** Movies, Series, and Music appear only when a matching visible library exists (mixed video libraries appear under both Movies and Series). Music opens an explicit unavailable page with Back. Audiobooks requires Settings > General > Show Audiobooks plus a visible audiobook library; turning the switch off from Audiobooks returns focus to Home.
- **Anchored library cascade:** focusing a library tab opens its centered panel at y=132 after 250 ms without fetching. Single-library tabs open Recommended, Browse, and Collections directly; multi-library tabs list up to six scrolling library rows (`360 px`) with a Right flyout (150 ms dwell) for modes. Explicit activation commits one library, never a merged scope. Selected library scopes persist per `(serverId, profileId, mediaType)` in `PublicStorage` (never credentials).
- **For You and Profile menus:** For You opens Watchlist and Favorites. Profile (`TVProfileDropdown`) lists History, capability-gated Requests (opens a root hub under the top bar; see [requests.md](requests.md)), capability + opt-in Watch Party ([watch-party.md](watch-party.md)), divider, Settings, the profile row, Change Account ([change-account.md](change-account.md)), and red Sign Out (confirmation via `TVSettingsConfirmationOverlay`). The profile row shows Add Profile when the open account's cached list holds one profile and `max_profiles` is absent or greater than one, Switch Profile when the count is not one, and hides when count is one and `max_profiles <= 1` (`ProfileMenuRow.row`). Optional `max_profiles` from `GET /api/v2/profiles` caches beside the count (an absent limit clears it); selecting Add Profile re-reads profiles and routes by that fresh list.
- **Add Profile vs Switch Profile return:** Switch Profile replaces the root with Who's watching (no Back to Browse). Cancelling Add Profile's form or unverified PIN prompt restores the retained page (Movies Browse returns to Sort; Home and other roots return to the avatar); completing creation or renewing PIN authority resets to fresh Home.
- **Root chrome removal:** Search, Details, Season, Person, Audiobook, and playback routes hide the top bar.

## Home and For You

- **Layout and ambient wash:** row band starts at y=596 (484 px tall, 80 px horizontal margin/reveal clearance); bottom-anchored marquee frame sits at x=88, y=256 (880×280). Backdrops render inside a composited 1228.8×756 top-right frame with a shared 190 px top scrim and a single 960×540 canvas `HeroWash` (four corner glows crossfading over 0.7 s, capped at two bitmaps for S95C raster performance; physical corners stay unmirrored in RTL matching Apple). A 512 px `heroPlaceholder` bitmap combines the frame backing and ThumbHash.
- **Marquee and enrichment:** text updates synchronously on card focus; backdrops wait 150 ms (or 320 ms hold cap on row change) before a 240 ms ease-in-out fade, revealing only after `HTMLImageElement.decode()`. Continue Watching warms its saved-file detail on load (queue of 4); other Home/For You/Recommended cards fetch item detail once after a 150 ms dwell (`marquee-rest`, immediate on row change; see [tv-focus.md](../tv-focus.md#never-fetch-on-focus)). For You also warms up to 16 cards missing content ratings (3 at a time). Dates in the Aired line format in the shown app language ([translation.md](../translation.md)).
- **Artwork sizing and Title Art:** initial loads request per-slot widths (`1344 px` backdrop fill, `880 px` logo × DPR) when capabilities are known, falling back to `large` (`2560 px` backdrop) rather than `small`. An optional cold-start capability upgrade merges artwork by identity while preserving focus and waiting while Card actions is open. Logos obey `ui.title_art` ([title-art.md](title-art.md)).
- **Cards, badges, and watch status:** standard 176×264 posters and 360×200 landscape stills (scaled 0.86 / 1.0 / 1.2 by `ui.card_presentation` for client family `tv`), 40 px gaps, 1.05 artwork lift with 4 px 70% white outline and 36 px blur shadow (no lift in reduced motion). Continue Watching chips and badges describe `user_data.last_file_id`'s file when still present, else `overlay_summary` (never guessed). Card presentation and overlay settings are read when Home loads and after Settings closes, never on focus. Missing/failed artwork renders `DefaultArtwork` (`src/ui/defaultArtwork.ts`). Posters draw `CardWatchStatus` (emerald check or remaining-episodes capsule) top-right and `CardOverlays` (all 7 presets, uploaded `valueImages`, SVG icons, wordmarks `HDR`/`HDR10`/`ATMOS`/`AV1`). Series cards show year ranges via `CardYears` on Home/catalog grids.
- **Rows and For You:** Home renders non-empty rows in server order (max 20 cards + `Explore all` opening a 60-card continuous grid; see [library-discovery.md](library-discovery.md#modes-layout-and-platform-substitutions)). Home with no rows shows Apple's `EmptyStateView` ("Nothing to watch yet"). For You reads `/recommendations/discover`, places `For You` rows first, and omits `Explore all`.

## Card actions

- Holding Select for 650 ms (`SELECT_HOLD_MS`) on movie, series, episode, season, or Calendar cards opens the `MediaStateMenuItems` context menu beside the card (Play/Resume, Watched, Favorites, Watchlist, `Not Interested` on poster cards when `user_state.not_interested` is present, and `Remove from Continue Watching`/`Next Up` on those Home rows). Short release runs normal activation (Details on Home rows; direct playback on episode rails; Continue Watching remote MediaPlay resumes directly).
- Opens immediately from card `user_state` (reading item detail only when absent), closes on selection, runs writes behind the screen via the shared Details mutation/readback owner, and shows `Couldn't Update Item` on failure. Uncertain writes hold and reconcile before retry; closing refreshes invalidated origin pages and restores focus by identity (or neighbor if removed).

## Text Search

- **Capability negotiation:** before the first non-empty query, reads `GET /catalog/search/capabilities` (failing visibly with Try Again on error). Uses `type=video_with_episodes` only when `allowed`, `state="available"`, and `video_with_episodes_scope: true`; otherwise `type=video`. Optional `people_media_scope: true` enables `GET /catalog/people?q&media_scope&limit=20`; optional `box_sets: true` enables `GET /catalog/box-sets` on All and Movies.
- **Querying and paging:** debounces 300 ms after edits (TV Done searches immediately), cancelling obsolete reads while keeping prior results visible until replacements land. Titles use `GET /catalog` (`limit=60`), appending continuously within eight rows of the end (`TVCatalogGrid.onNearEnd`) and restarting once on `invalid_cursor`.
- **Layout and supplements:** 1444 px column (6 columns Compact/Standard, 5 columns Large), capsule All/Movies/Series filters (only when nonblank), People rail above titles (failure does not hide usable titles), and an independent 12-card `Available to request` rail (`requestOperations.search`, trimmed query length > 1, enabled Requests capability). Opening Search starts empty on the input; Back from Details restores query, depth, and focused card. When the Samsung IME opens (`visualViewport` height <= 824 px), Search switches to the compact keyboard-up header ([tv-focus.md](../tv-focus.md#samsung-remote-specifics)).

## Details and preplay

Details hero entry, action row, popovers, inline season/episode rail, directional scroll, and accepted Apple TV differences live in [details-actions.md](details-actions.md).

- Movie and Series Details share Home's 1228.8×756 backdrop frame and `TVDetailPageSurface` 42% base wash; Detail artwork requests negotiate `460 px` poster and `200 px` cast widths consistently across re-reads, and episode rails request `still_width = 360 * DPR`.
- Cast & Crew caps at 24 deduplicated entries opening [person-filmography.md](person-filmography.md). Trailers & More lists local extras (playing from zero, resolving missing file IDs via `/versions` on Select) and YouTube cards (Select stays on card; no verified Samsung YouTube handoff).
- Audiobooks open their own detail page (cover, author/narrator, chapters, inert playback actions until audiobook playback ships).

## Preplay audio, subtitles and resume

- **Audio selection:** offers Auto plus the displayed file's ordered `audio_tracks` (`file:{fileId}:audio:{ordinal}`). Explicit picks persist via `PUT /audio-prefs/{key}` and Auto clears via `DELETE /audio-prefs/{key}` (playback waits for confirmation). Changing version clears explicit audio; selecting audio alone never pins a version.
- **Subtitle selection:** offers Auto, Off, and catalog tracks (semantic metadata only). Explicit picks (including Off) persist via `PUT /subtitle-prefs/{key}` and Auto clears via `DELETE` (sidecars without a stream index remain visit-only). Before AVPlay opens, the player matches explicit choices against the authoritative first plan (replanning if needed) and fails visibly rather than silently playing a wrong track.
- **Version selection:** visit-only; sets `allow_alternate_versions: false` and carries exact `file_id` and duration (5 s end margin) to playback.
- **Fresh resume:** Play/Resume captures file, audio/subtitle intent, version pin, and focus before reading `GET /api/v2/watch/{id}?file_id=...` (3 s timeout; falls back to confirmed cached progress only on network/timeout/501/503). Explicit Start Over sends `start_position: 0` without a watch read. Back, teardown, or Authority changes cancel handoff; playback return restores initiating focus.

## Settings integration

Settings shares `FocusHost` across the category rail, control pane, and pickers (category focus previews without network requests; Back returns picker -> pane -> rail -> Browse avatar).

- **General:** TV User, Profile at Launch ([profile-launch.md](profile-launch.md)), App Language ([translation.md](../translation.md)), Title Pages ([title-art.md](title-art.md)), Theme Music, Cards & Posters (Show Advisory Age, Poster Size), and Show Audiobooks.
- **Playback:** [saved playback defaults](../playback/playback-quality.md#saved-playback-settings) (Resolution, Maximum Bitrate, Lower quality when buffering, conditional Learned limit, Connection speed, Audio Language, HDR, Episodes controls, Spoilers, Video/Audiobooks skip intervals, Reset).
- **Subtitles:** Language, Behavior, Show Forced Subtitles, conditional Metadata Language, and Appearance ([subtitle-appearance.md](../playback/subtitle-appearance.md)).
- **Server:** Active Server info, [Accounts](change-account.md), Restore All Libraries (when `ui.disabled_library_ids` is nonempty), About, and Extra Features ([watch-party.md](watch-party.md)).
- See [docs/settings.md](../settings.md) for the complete Settings contract, styling, and AVPlay exclusions, and [docs/evidence/simulator-evidence.md](../evidence/simulator-evidence.md) for signed `.wgt` and Apple TV comparison gates.
